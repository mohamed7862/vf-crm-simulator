Call Tone (الكول تون) • Subscription: Monthly = 3 LE | 15 Days = 1.5 LE | 7 Days = 75 PT | Daily = 10 PT[cite: 1].

• On Bill (Authorized): Add via *247# or Siebel Supplementary Tab[cite: 1]. If added by Auth, only Auth can remove it[cite: 1].

Multi-Factor Authentication (MFA) • 1-Factor MFA: Name & Full National ID OR Date of Birth + Last 7 digits from ID[cite: 1]. (Used for: MI Act/Deact, On Bill add, Roaming/Int'l control lines, Plan change ≤ 3 lines)[cite: 1].
• 2-Factor MFA: Name + Full ID + Address + Choose 3 from 6 verifications (Last Bill, E-Mail, Line count, Auth balance, Last payment, Bill Cycle)[cite: 1]. (Used for: SIM Swap On Spot, Delegation SR, Suspension, Plan change > 3 lines, Churn, Transfer Ownership, Itemized calls)[cite: 1].
